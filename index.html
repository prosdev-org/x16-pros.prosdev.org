x16-PRos: fast and lightweight

A hand-written operating system that fits on a single floppy. It has a terminal, GUI, cooperative multitasking, its own assembler and a MS-DOS compatibility layer that runs real MS-DOS software.

Small

The kernel is < 64kib. The whole system with 40+ programs fits on a 1.44 MB floppy.

Three interfaces

Command line, TUI programs and a windowed GUI with draggable, resizable windows.

Runs MS-DOS software

Windows 1.01, Windows 2.03, DOOM and Turbo C run natively through the compatibility layer.

MS-DOS сompatibility

x16-PRos emulates the MS-DOS system call on top of it`s kernel, enabling the native execution of .COM and .EXE (MZ) programs. Compatibility is not yet complete, but it is being actively improved. At the moment, a large number of programs are already running.

40+ built-it programs

Standard software package includes editors, file utilities, a native assembler, hex editor, media players, games and windowed GUI applications.

System requirements

Required

  • CPU: Intel 80386
  • RAM: 640 KB conventional
  • Video: VGA
  • Storage: 1.44 MB floppy
  • Input: PS/2 or USB keyboard
  • Firmware: BIOS, or UEFI with CSM

Recommended

  • CPU: Intel 80486 or better
  • RAM: 640 KB conventional
  • Video: VGA
  • Storage: hard disk (5 MB or more)
  • Input: keyboard and PS/2 mouse
  • Firmware: BIOS, or UEFI with CSM
  • Sound: PC speaker

Running x16-PRos

Write the image to a USB stick and boot a real machine, or start it in an emulator.

Real hardware Emulator
bash
user@linux:~/x16-PRos$ QEMU

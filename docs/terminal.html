The shell

x16-PRos boots into its own shell. Typing the name of an executable runs it: the shell looks in BIN.DIR for .BIN and .COM programs, in PLE.DIR for .PLE programs, and finally in the current directory. The extension is optional.

The commands below are built into the shell itself. Anything else you type is treated as a program name.

Information

CommandDescription
helpHelp screen with all of these comands
infoSystem information
verVersion of the PRos terminal
dateCurrent date, DD/MM/YY
timeCurrent time, HH:MM:SS

Files

CommandSyntaxDescription
dirdirList the current directory with sizes and a file count
catcat <file>Print the contents of a text file
sizesize <file>File size in bytes
deldel <file>Delete a file
copycopy <src> <dst>Copy a file within the current directory
renren <old> <new>Rename a file
touchtouch <file>Create an empty file
writewrite <file> <text>Write text into a file, replacing what was there

Directories

CommandSyntaxDescription
cdcd <dir>Enter a directory. The .DIR extension may be left off
cdcd ..Go up one level
cdcd /Go back to the root
mkdirmkdir <name>Create a directory
deldirdeldir <name>Delete a directory. It has to be empty

Screen and images

CommandSyntaxDescription
clsclsClear the screen and reapply the current theme
viewview <file.bmp>Show a BMP image, up to 320×240 in 256 colours
view <file> -upscaleScale the image to twice its size
view <file> -stretchStretch the image to fill the screen

Multitasking

CommandSyntaxDescription
bgbg <file.ple>Start a PLE program in the background and return to the prompt

Use PS.BIN to list running tasks and KILL.BIN to stop one.

System

CommandDescription
rebootRestart the machine immediately
shutShut down through APM. Only works on APM-capable hardware
exitLeave the shell and return to the bootloader

Not commands, but programs

Several things that look like shell commands are separate executables in BIN.DIR. They are started the same way and take arguments the same way:

ProgramDoes
cpuCPU and register information
dlistLists every detected drive with its size and usage
treePrints the directory tree
grep <file> <text>Finds text in a file
head <file> / tail <file>First or last ten lines of a file
ps / kill <id>List and terminate background tasks
prasm <src.asm>Assemble a program without leaving the system

The full list is on the software page.

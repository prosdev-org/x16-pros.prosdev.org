Building a program

Every example below is a complete file. Assemble one with NASM on your own machine:

nasm -f bin hello.asm -o HELLO.BIN

Then copy it onto the disk image with mtools, or put the source in programs/ and let build-linux.sh pick it up.

Hello, world

A .BIN program is a flat binary loaded at offset 0x8000. It ends with a near ret, which hands control back to the shell.

[BITS 16]
[ORG 0x8000]

start:
    mov ah, 0x01          ; print a white string
    mov si, hello_msg
    int 0x21

    ret                   ; back to the terminal

hello_msg db 'Hello, PRos!', 10, 13, 0

Coloured output

There is four printing functions in fixed colours. For anything else, set a colour once and print with function 0x08.

[BITS 16]
[ORG 0x8000]

start:
    mov ah, 0x02          ; green
    mov si, msg
    int 0x21

    mov ah, 0x07          ; set the current colour
    mov bl, 0x0E          ; yellow
    int 0x21

    mov ah, 0x08          ; print with current colour
    mov si, msg
    int 0x21

    ret

msg db 'Hello, PRos!', 10, 13, 0

Reading the command line

The shell copies whatever followed the program name into a buffer and hands the pointer to the program in SI register.

[BITS 16]
[ORG 0x8000]

start:
    mov [params], si

    mov ah, 0x01
    mov si, label
    int 0x21

    mov ah, 0x01
    mov si, [params]
    int 0x21

    mov ah, 0x05
    int 0x21
    ret

params  dw 0
label   db 'cmd args: ', 0

Reading a file

Load a whole file into memory and print it. 0x02 loads at an offset inside the program's own segment; for anything that might exceed 64 KB, use 0x10 and give it a segment of its own.

[BITS 16]
[ORG 0x8000]

start:
    mov ah, 0x04          ; does it exist?
    mov si, fname
    int 0x22
    jc  .missing

    mov ah, 0x02          ; load it
    mov si, fname
    mov cx, buffer
    int 0x22

    mov bx, buffer        ; NUL-terminate what we read
    add bx, ax
    mov byte [bx], 0

    mov ah, 0x01
    mov si, buffer
    int 0x21
    ret

.missing:
    mov ah, 0x04
    mov si, err
    int 0x21
    ret

fname  db 'README.TXT', 0
err    db 'no such file', 10, 13, 0
buffer times 4096 db 0

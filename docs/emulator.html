Running in an emulator

The quickest way to try x16-PRos.

On this page

  • QEMU
  • DOSBox
  • VirtualBox
  • In the browser

QEMU

The simplest option and the one the project is developed against. Install it from your package manager:

sudo apt install qemu-system-x86     # Debian, Ubuntu
sudo pacman -S qemu-full             # Arch
sudo dnf install qemu-system-x86     # Fedora

Then boot the floppy image:

qemu-system-x86_64 -fda x16-PRos.img

With sound

x16-PRos drives the PC speaker, AdLib and Sound Blaster. To hear any of it, hand QEMU an audio backend and attach the devices:

qemu-system-x86_64 \
  -audiodev pa,id=snd0 \
  -machine pcspk-audiodev=snd0 \
  -device adlib,audiodev=snd0 \
  -fda x16-PRos.img

Use -audiodev alsa,id=snd0 if you are not running PulseAudio or PipeWire.

With a hard disk

To try the installer, or to run the bundled copy of DOOM, attach a hard disk image as well:

qemu-system-x86_64 -fda x16-PRos.img -hda HDD.img

Building the project from source produces both images and a run-linux.sh that wires all of this up for you.

DOSBox

Worth using for one specific reason: it can slow the emulated CPU down. Old DOS games assume a machine of a certain speed, and under QEMU they run far too fast to be playable.

dosbox -c "boot x16-PRos.img"

Adjust the speed with Ctrl+F11 and Ctrl+F12 while the system is running.

VirtualBox

Create a machine of type Other / DOS, disable EFI, and attach the image as a floppy. For a hard disk install add an IDE disk.

In the browser

x16-PRos also boots under v86. Load the image as a floppy. It is the fastest way to show somebody the system without them installing anything.

Calling convention

Every service is reached with a software interrupt. The function number goes in AH, the arguments in the other registers. Unless a function is documented as returning something, all registers are preserved. Failures are reported by setting the carry flag.

INT 0x21 Output API

Text output in VGA 0x12 (640×480, 16 colours).

Date and time

AHFunctionOutput
0x0AGet system timeCH = hours, CL = minutes, DH = seconds
0x0BGet system dateCH = century, CL = year, DH = month, DL = day

Both read the RTC through BIOS INT 0x1A and apply the offset from CONF.DIR/TIMEZONE.CFG.

INT 0x22 File system API

Names are 8.3 and case-insensitive, uppercased on the way in. Everything happens relative to the current directory of the current drive.

Files

0x01Get file listSI = bufferBX:CX = total size, DX = file count
0x02Load fileSI = name, CX = offsetBX = size
0x03Write fileSI = name, BX = data, CX = sizeCF on error
0x04File existsSI = nameCF clear if it exists
0x05Create empty fileSI = nameCF on error
0x06Delete fileSI = nameCF on error
0x07Rename fileSI = old, DI = newCF on error
0x08Get file sizeSI = nameBX = size

Large files

AHFunctionInputOutput
0x10Load huge fileSI = name, CX = offset, DX = segmentDX:AX = size
0x13Write huge fileSI = name, CX:DX = source, BX/DI = sizeCF on error

These two are not limited to 64 KB — the data may span segments.

Drives

Streaming new

Up to eight files can be open at once. Reading and writing happen in pieces, so the size of a file is not limited by how much memory is free. Some of the MS-DOS comp. layer calls is built on top of this.

0x150x01ReadBX = handle, CX = bytes, DX:DI = destinationAX = bytes read, 0 at EOF
0x150x02WriteBX = handle, CX = bytes, DX:DI = sourceAX = bytes written
0x150x03SeekBX = handle, CX:DX = positionCF on a bad handle
0x150x04CloseBX = handleUpdates the directory entry
INT 0x23 System API

Memory, tasks and the mouse.

Memory

AHFunctionInputOutput
0x00Get version—AX = version
0x01AllocateBX = bytesAX = segment, CF on failure
0x02FreeAX = segmentCF if the segment is unknown
0x03Get free bytes—DX:AX = free bytes

The heap runs from segment 0x3000 to 0xA000, 448 KB in total, shared by every running program.

Tasks

AHFunctionInputOutput
0x10Run a PLE programSI = filenameCF on load failure
0x11Run a PLE program in the backgroundSI = filenameAX = task id
0x12Terminate the current task—Does not return
0x13Yield—Hands the CPU to the next ready task
0x14SleepCX = BIOS ticksOne tick is about 55 ms
0x15Get current task id—AL = id
0x16Read a key, yielding while idle—AX = as INT 16h AH=0
0x17Query a task slotBL = idAL = state, AH = flags, CX = base segment, DL = parent
0x18Kill a taskBL = idCF on failure
0x19Get a task nameBL = id, DI = bufferBuffer must hold 16 bytes
0x34Reparent a taskBL = id, BH = new parentCF on a bad id

Scheduling is cooperative, not preemptive: a task keeps the CPU until it yields, sleeps or waits for a key. There are eight slots, one of which belongs to the kernel.
